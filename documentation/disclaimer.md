## 3. Visual Media Policy

The following rules are binding for all contributors.

- The README file must contain text only. It must not embed images and must not
  contain emojis.
- All screenshots, diagrams, logos, and other visual media must be stored in the
  `screenshots` folder in the project directory.
- File names must be descriptive and written in lower case with hyphens, for
  example `student-dashboard-cart.png`.
- Documentation that needs to reference an image must link to the file in the
  `screenshots` folder rather than embedding it in the README.
- Diagrams inside documentation should be expressed as fenced text blocks where
  a text representation is sufficient.

## 5. Reporting Problems

If you encounter a problem or an error, do not attempt to correct it silently or
outside the project. Instead:

1. Search the existing issues on the GitHub repository to avoid duplicates.
2. Open a new issue describing the problem, the steps to reproduce it, the
   expected behaviour, and the observed behaviour.
3. Where you already have a correction, submit a pull request that references
   the issue.

This ensures that the maintainers and contributors can review, verify, and
address the matter appropriately. The full process is described in
[contributing.md](./contributing.md).

## 6. Academic and Demonstration Use

Campus Eats is an academic and demonstration project. It is not certified for
production use. In particular:

- Demonstration accounts and their credentials are published openly for review
  purposes and must be removed before any real deployment.
- Authentication is simplified and does not implement production grade password
  hashing or server enforced authorisation.
- Reports and revenue figures are derived from demonstration data and must not
  be relied upon for financial or operational decisions.
